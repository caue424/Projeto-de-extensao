##  Descrição do Projeto
Esta aplicação foi desenvolvida com o objetivo de gerenciar e registrar o ponto de funcionários de forma prática e eficiente. O sistema permite o acompanhamento detalhado da jornada de trabalho, oferecendo funcionalidades essenciais tanto para os colaboradores quanto para a gestão.

## Principais Funcionalidades:
* **Registro de Ponto:** Marcação dos horários de entrada e saída.

##  Tecnologias Utilizadas

 **Back-end:** Java 

*Projeto desenvolvido para fins acadêmicos - 2026.
